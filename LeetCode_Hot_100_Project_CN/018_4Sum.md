# 18. 四数之和 (4Sum)

### 问题描述
给定一个包含 `n` 个整数的数组 `nums` ，返回所有满足以下条件的唯一四元组 `[nums[a], nums[b], nums[c], nums[d]]` ：
*   `0 <= a, b, c, d < n`
*   `a`、`b`、`c` 和 `d` 互不相同。
*   `nums[a] + nums[b] + nums[c] + nums[d] == target`
你可以按任何顺序返回答案。

**示例：**
输入: `nums = [1,0,-1,0,-2,2], target = 0`
输出: `[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]`

输入: `nums = [2,2,2,2,2], target = 8`
输出: `[[2,2,2,2]]`

限制条件:
*   `1 <= nums.length <= 200`
*   `-10^9 <= nums[i] <= 10^9`
*   `-10^9 <= target <= 10^9`
[查看LeetCode问题描述](https://leetcode.cn/problems/4sum/)

### 最优解法思路
此问题是“三数之和”的扩展。策略是先对数组进行排序，然后使用嵌套循环来固定四元组的前两个数字。对于剩下的两个数字，则在数组的其余部分应用双指针技术。
1.  **排序数组：** 对 `nums` 进行排序 (O(N log N))。
2.  **外层循环（前两个元素）：** 使用 `i` 迭代第一个元素，使用 `j` 迭代第二个元素。跳过 `nums[i]` 和 `nums[j]` 的重复项，以避免冗余的四元组。
3.  **双指针扫描（后两个元素）：** 对于每一对 `(nums[i], nums[j])`，在子数组 `nums[j+1 ... n-1]` 上使用 `left` 和 `right` 指针。查找 `nums[left]` 和 `nums[right]`，使其和等于 `target - (nums[i] + nums[j])`。处理和时使用 `long` 类型以防止溢出。当找到一个四元组时，跳过 `nums[left]` 和 `nums[right]` 的重复项。根据与剩余目标的比较来调整 `left` 和 `right`。
总体时间复杂度：O(N^3)。

### 解题步骤详解
1.  对输入数组 `nums` 进行排序。
2.  初始化一个空的 `List<List<Integer>> result`。
3.  如果 `nums.length < 4`，则返回 `result`。
4.  外层循环，`i` 从 `0` 到 `n-4`（第一个元素）：
    a.  跳过重复的 `nums[i]`（检查 `if i > 0 && nums[i] == nums[i-1]`）。
    b.  （可选剪枝：检查使用 `nums[i]` 的最小可能和是否已超过 `target`，或者最大可能和是否小于 `target`）。
5.    内层循环，`j` 从 `i+1` 到 `n-3`（第二个元素）：
    a.  跳过重复的 `nums[j]`（检查 `if j > i+1 && nums[j] == nums[j-1]`）。
    b.  （可选剪枝：对 `nums[i] + nums[j]` 进行类似检查）。
    c.  初始化 `left = j+1`，`right = n-1`。
    d.  计算 `twoSumTarget = (long)target - nums[i] - nums[j]`。
    e.  当 `left < right` 时：
        i.   `currentPairSum = (long)nums[left] + nums[right]`。
        ii.  如果 `currentPairSum == twoSumTarget`：将 `(nums[i], nums[j], nums[left], nums[right])` 添加到 `result`。通过递增 `left` 来跳过 `nums[left]` 的重复项。通过递减 `right` 来跳过 `nums[right]` 的重复项。然后，递增 `left` 并递减 `right` 以继续搜索。
        iii. 否则如果 `currentPairSum < twoSumTarget`：递增 `left`。
        iv.  否则：递减 `right`。
6.  返回 `result`。

### Java 代码实现
```java
import java.util.ArrayList; // 用于 ArrayList
import java.util.Arrays;   // 用于 Arrays.sort() 和 Arrays.asList()
import java.util.List;     // 用于 List 接口

class Solution {
    // 方法：找出所有和为 target 的唯一四元组
    public List<List<Integer>> fourSum(int[] nums, int target) {
        List<List<Integer>> result = new ArrayList<>();
        // 如果数组元素少于 4 个，则无法形成四元组。
        if (nums == null || nums.length < 4) {
            return result;
        }

        // 对数组进行排序以使用双指针技术并处理重复项。
        Arrays.sort(nums);
        int n = nums.length;

        // 四元组第一个元素的外层循环
        for (int i = 0; i < n - 3; i++) {
            // 跳过第一个元素的重复项以避免冗余计算
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }
            
            // 可选剪枝 1：如果使用 nums[i] 的最小可能和超过 target
            // (需要注意大的负数和 target)
            // if ((long)nums[i] + nums[i+1] + nums[i+2] + nums[i+3] > target && nums[i] > 0 && target > 0) break; 
            // 可选剪枝 2：如果使用 nums[i] 的最大可能和小于 target
            // if ((long)nums[i] + nums[n-3] + nums[n-2] + nums[n-1] < target && nums[i] < target && target > 0) continue;


            // 四元组第二个元素的第二个循环
            for (int j = i + 1; j < n - 2; j++) {
                // 跳过第二个元素的重复项
                if (j > i + 1 && nums[j] == nums[j - 1]) {
                    continue;
                }

                // 前两个元素和的可选剪枝
                // if ((long)nums[i] + nums[j] + nums[j+1] + nums[j+2] > target && nums[i] > 0 && nums[j] > 0 && target > 0) break;
                // if ((long)nums[i] + nums[j] + nums[n-2] + nums[n-1] < target && nums[i] < target && nums[j] < target && target > 0) continue;

                // 剩余两个元素的双指针
                int left = j + 1;
                int right = n - 1;
                // 计算数对 (nums[left], nums[right]) 的目标和
                // 如果 target 或 nums[i/j] 很大，则在减法期间使用 long 以防止溢出。
                long remainingTarget = (long)target - nums[i] - nums[j];

                while (left < right) {
                    long currentTwoSum = (long)nums[left] + nums[right];

                    if (currentTwoSum == remainingTarget) {
                        // 找到了一个四元组
                        result.add(Arrays.asList(nums[i], nums[j], nums[left], nums[right]));

                        // 跳过第三个元素 (nums[left]) 的重复项
                        while (left < right && nums[left] == nums[left + 1]) {
                            left++;
                        }
                        // 跳过第四个元素 (nums[right]) 的重复项
                        while (left < right && nums[right] == nums[right - 1]) {
                            right--;
                        }

                        // 移动指针以查找其他数对
                        left++;
                        right--;
                    } else if (currentTwoSum < remainingTarget) {
                        // 和太小，递增左指针
                        left++;
                    } else { // currentTwoSum > remainingTarget
                        // 和太大，递减右指针
                        right--;
                    }
                }
            }
        }
        return result;
    }
}
```

### 核心数据结构
**数组 (`int[] nums`)：** 输入，进行原地排序。**`List<List<Integer>>`：** 用于存储生成的唯一四元组。

### 主要算法思想
**排序：** 必要的预处理 (O(N log N))。**嵌套循环与双指针：** 两个外层循环固定前两个元素；一个内层双指针扫描查找其余两个元素 (搜索时间 O(N^3))。**重复项处理：** 用于跳过重复项的逻辑，以确保四元组的唯一性。
