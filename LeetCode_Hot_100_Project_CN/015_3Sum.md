# 15. 三数之和 (3Sum)

### 问题描述
给定一个整数数组 `nums`，返回所有满足 `i != j`、`i != k` 且 `j != k`（即索引互不相同）并且 `nums[i] + nums[j] + nums[k] == 0` 的三元组 `[nums[i], nums[j], nums[k]]`。

解决方案集不得包含重复的三元组。输出的顺序以及每个三元组中数字的顺序无关紧要。

**示例：**
输入: `nums = [-1,0,1,2,-1,-4]`
输出: `[[-1,-1,2],[-1,0,1]]`
[查看LeetCode问题描述](https://leetcode.cn/problems/3sum/)

### 最优解法思路
为了有效地在数组 `nums` 中找到所有和为零的唯一三元组，一个常用且有效的策略是首先对数组进行排序。排序使得我们可以使用双指针技术来查找数对，并且也简化了跳过重复三元组的过程。
1.  **排序数组：** 按非降序对 `nums` 进行排序。
2.  **迭代并固定第一个元素：** 使用索引 `i` 遍历排序后的数组。`nums[i]` 是潜在三元组的第一个元素。
    *   **优化：** 如果 `nums[i] > 0`，则以 `nums[i]` 开头的任何三元组都不可能和为 0。跳出循环。
    *   **跳过 `nums[i]` 的重复项：** 如果 `i > 0` 且 `nums[i] == nums[i-1]`，则跳过以避免重复的三元组。
3.  **双指针扫描：** 对于每个 `nums[i]`，在 `nums[i+1 ... n-1]` 中找到两个和为 `-nums[i]` 的数字。初始化 `left = i + 1`，`right = nums.length - 1`，`target = -nums[i]`。当 `left < right` 时：
    *   如果 `nums[left] + nums[right] == target`：找到了一个三元组。添加 `(nums[i], nums[left], nums[right])`。通过将 `left` 前进到跳过相同值之后，并将 `right` 前进到跳过相同值之后来跳过 `nums[left]` 和 `nums[right]` 的重复项。然后 `left++`，`right--`。
    *   否则如果 `nums[left] + nums[right] < target`：递增 `left`。
    *   否则：递减 `right`。
初始 O(N log N) 排序后的总体时间复杂度为 O(N^2)。

### 解题步骤详解
1.  对输入数组 `nums` 进行排序。
2.  初始化一个空列表 `resultTriplets`。
3.  循环 `i` 从 `0` 到 `nums.length - 2`：
    a.  如果 `nums[i] > 0`，则跳出循环（优化）。
    b.  如果 `i > 0` 且 `nums[i] == nums[i-1]`，则继续（跳过第一个元素的重复项）。
    c.  初始化 `left = i + 1`，`right = nums.length - 1`。
    d.  当 `left < right` 时：
        i.   计算 `sum = nums[i] + nums[left] + nums[right]`。
        ii.  如果 `sum == 0`：
     1. 将 `Arrays.asList(nums[i], nums[left], nums[right])` 添加到 `resultTriplets`。
     2. 递增 `left`。当 `left < right` 且 `nums[left] == nums[left-1]` 时，递增 `left`。
     3. 递减 `right`。当 `left < right` 且 `nums[right] == nums[right+1]` 时，递减 `right`。
     （注意：对于步骤 2 和 3，如果指针已经移动过一次，则应为 `nums[left] == nums[left-1]` 和 `nums[right] == nums[right+1]`；或者，在为下一个不同数对移动它们之前，为 `nums[left] == nums[left+1]` 和 `nums[right] == nums[right-1]`。代码示例通过先前进然后跳过来正确处理此问题。）
        iii. 否则如果 `sum < 0`：递增 `left`。
        iv.  否则 (`sum > 0`)：递减 `right`。
4.  返回 `resultTriplets`。

### Java 代码实现
```java
import java.util.ArrayList; // 用于 ArrayList
import java.util.Arrays;   // 用于 Arrays.sort() 和 Arrays.asList()
import java.util.List;     // 用于 List 接口

class Solution {
    // 方法：找出数组中所有和为零的唯一三元组
    public List<List<Integer>> threeSum(int[] nums) {
        // 用于存储结果三元组的列表
        List<List<Integer>> resultTriplets = new ArrayList<>();

        // 一个三元组至少需要 3 个数字。如果少于此数量，则返回空列表。
        if (nums == null || nums.length < 3) {
            return resultTriplets;
        }

        // 对数组进行排序。这对于双指针方法
        // 以及有效跳过重复三元组至关重要。
        Arrays.sort(nums);

        // 遍历数组。`nums[i]` 将是潜在三元组的第一个元素。
        // 我们只需要遍历到 `nums.length - 2`，因为我们需要至少两个元素
        // （在 `left` 和 `right` 处）来组成一个三元组。
        for (int i = 0; i < nums.length - 2; i++) {
            // 优化：如果当前数字（由于已排序，是潜在三元组中最小的数字）
            // 已经大于 0，则没有三元组可以和为 0。
            if (nums[i] > 0) {
                break;
            }

            // 跳过第一个元素 (`nums[i]`) 的重复值。
            // 如果 `i > 0`（不是第一个元素）且 `nums[i]` 与 `nums[i-1]` 相同，
            // 则表示我们已经处理过以此值开头的三元组，因此跳过。
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            // 为数组的其余部分初始化两个指针。
            int left = i + 1;             // `left` 从 `nums[i]` 之后开始
            int right = nums.length - 1;  // `right` 从数组末尾开始

            // 使用双指针技术查找另外两个数字
            while (left < right) {
                int currentSum = nums[i] + nums[left] + nums[right];

                if (currentSum == 0) {
                    // 找到了一个和为零的三元组
                    resultTriplets.add(Arrays.asList(nums[i], nums[left], nums[right]));

                    // 跳过第二个元素 (`nums[left]`) 的重复值
                    // 只要 `left` 小于 `right` 且下一个元素相同，就将 `left` 指针向前移动。
                    while (left < right && nums[left] == nums[left + 1]) {
                        left++;
                    }
                    // 跳过第三个元素 (`nums[right]`) 的重复值
                    // 只要 `right` 大于 `left` 且前一个元素相同，就将 `right` 指针向后移动。
                    while (left < right && nums[right] == nums[right - 1]) {
                        right--;
                    }

                    // 向内移动指针以查找下一个潜在的不同数对
                    left++;
                    right--;
                } else if (currentSum < 0) {
                    // 如果和小于零，我们需要一个更大的和。
                    // 将 `left` 指针向右移动以包含一个更大的数字。
                    left++;
                } else { // currentSum > 0
                    // 如果和大于零，我们需要一个更小的和。
                    // 将 `right` 指针向左移动以包含一个更小的数字。
                    right--;
                }
            }
        }
        // 返回找到的唯一三元组列表
        return resultTriplets;
    }
}
```

### 核心数据结构
**数组 (`int[] nums`)：** 输入，进行原地排序。**`List<List<Integer>>`：** 用于存储生成的唯一三元组。

### 主要算法思想
**排序：** 预处理步骤，对于双指针方法和重复项处理至关重要。**双指针：** 用于在子数组上高效地查找和为特定目标的数对。**重复项跳过逻辑：** 对于确保结果中三元组的唯一性至关重要。
