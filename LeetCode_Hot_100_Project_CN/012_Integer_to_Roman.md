# 12. 整数转罗马数字 (Integer to Roman)

### 问题描述
给定一个整数 `num`（保证在 1 到 3999 的范围内），将其转换为其罗马数字表示形式。

罗马数字由七个不同的符号表示：I、V、X、L、C、D 和 M。
```
符号       值
I             1
V             5
X             10
L             50
C             100
D             500
M             1000
```
例如，`2` 在罗马数字中写作 `II`，只是两个 1 相加。`12` 写作 `XII`，即 `X + II`。数字 `27` 写作 `XXVII`，即 `XX + V + II`。

罗马数字通常从左到右按从大到小的顺序书写。但是，数字 4 不写作 `IIII`。相反，数字 4 写作 `IV`。因为 1 在 5 之前，我们减去它得到 4。同样的原则适用于数字 9，写作 `IX`。有六种情况使用减法：
*   `I` 可以放在 `V` (5) 和 `X` (10) 之前，构成 4 和 9。
*   `X` 可以放在 `L` (50) 和 `C` (100) 之前，构成 40 和 90。
*   `C` 可以放在 `D` (500) 和 `M` (1000) 之前，构成 400 和 900。
[查看LeetCode问题描述](https://leetcode.cn/problems/integer-to-roman/)

### 最优解法思路
整数到罗马数字的转换可以通过贪心算法有效地处理。关键是预先定义一个罗马数字符号及其对应整数值的列表，并按值降序排列。至关重要的是，此列表必须包含减法组合（如 "CM" 代表 900，"CD" 代表 400，"XC" 代表 90，"XL" 代表 40，"IX" 代表 9，以及 "IV" 代表 4），以确保得到最短且正确的罗马数字形式。

该算法遍历这些预定义的值。对于每个值，它检查该值可以从当前输入数字中减去多少次。对于每次可以减去的情况，我们将相应的罗马符号附加到结果中，并从输入数字中减去该值。此过程继续处理数字的余数，直到数字变为零。因为我们总是首先尝试匹配最大的可能罗马数字值，所以这种贪心选择会产生正确的表示。

### 解题步骤详解
1.  定义两个数组：
    *   `values`：一个整数数组，表示罗马数字的基本值，包括减法形式，按降序排列。例如：`[1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1]`。
    *   `symbols`：一个字符串数组，包含相应的罗马数字符号。例如：`["M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"]`。
2.  初始化一个空的 `StringBuilder`（例如 `romanBuilder`）来构造罗马数字字符串。
3.  从最大值到最小值遍历 `values` 数组（并使用相同的索引 `i` 遍历 `symbols` 数组）。
    a.  对于当前的 `values[i]`：当输入数字 `num` 大于或等于 `values[i]` 时：
        i.  将 `symbols[i]` 附加到 `romanBuilder`。
        ii. 从 `num` 中减去 `values[i]`。
    b.  如果 `num` 变为 0，则转换完成。
4.  循环结束后，将 `romanBuilder` 转换为字符串并返回。

### Java 代码实现
```java
class Solution {
    // 方法：将整数转换为其罗马数字表示形式
    public String intToRoman(int num) {
        // 定义整数值及其对应的罗马数字符号。
        // 这些必须按从大到小的顺序排列，并且必须包括
        // 减法形式（例如，900 作为 "CM"，40 作为 "XL"），以使贪心方法能够正确工作。
        int[] values = {1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1};
        String[] symbols = {"M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"};

        // StringBuilder 在循环中连接字符串时效率很高。
        StringBuilder romanBuilder = new StringBuilder();

        // 遍历每个值-符号对。
        // 只要有值需要检查且数字 `num` 大于 0，循环就继续。
        for (int i = 0; i < values.length && num > 0; i++) {
            // 对于当前值（例如，1000，然后是 900，然后是 500，依此类推），
            // 检查它可以从 num 中“减去”多少次。
            while (num >= values[i]) {
                // 如果当前值可以被减去，则意味着此罗马符号是表示形式的一部分。
                num -= values[i]; // 从 num 中减去该值。
                romanBuilder.append(symbols[i]); // 附加相应的罗马符号。
            }
        }

        // 将 StringBuilder 转换为 String 并返回。
        return romanBuilder.toString();
    }
}
```

### 核心数据结构
**数组：** 使用两个数组（`values` 和 `symbols`）来存储整数值及其罗马数字字符串表示之间的映射。**StringBuilder：** 用于通过附加符号来高效地构造生成的罗马数字字符串。

### 主要算法思想
**贪心算法：** 解决方案的核心。通过从大到小迭代预定义的罗马数字值，并重复减去适合剩余整数的最大可能值，我们贪心地构造罗马数字。这是可行的，因为罗马数字系统（在其减法规则在我们的映射中正确排序的情况下）具有适合这种贪心选择的结构。
