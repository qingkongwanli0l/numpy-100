# 14. 最长公共前缀 (Longest Common Prefix)

### 问题描述
编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

**示例 1：**
输入: `strs = ["flower","flow","flight"]`
输出: `"fl"`

**示例 2：**
输入: `strs = ["dog","racecar","car"]`
输出: `""`
解释: 输入不存在公共前缀。

**限制条件：**
*   `1 <= strs.length <= 200`
*   `0 <= strs[i].length <= 200`
*   `strs[i]` 仅由小写英文字母组成。
[查看LeetCode问题描述](https://leetcode.cn/problems/longest-common-prefix/)

### 最优解法思路
“垂直扫描”方法是查找最长公共前缀的一种直观且有效的方法。其思想是逐列比较输入数组中所有字符串在相同索引处的字符。
1.  **处理边界情况：** 如果输入数组 `strs` 为 null 或为空，则返回 `""`。如果数组仅包含一个字符串，则该字符串本身就是最长公共前缀。
2.  **逐个字符迭代（垂直）：** 使用第一个字符串 (`strs[0]`) 作为参考。遍历其字符（索引 `i`）。对于每个字符 `currentChar = strs[0].charAt(i)`，将其与所有其他字符串 `strs[j]` 中的 `strs[j].charAt(i)` 进行比较。如果有任何字符串短于索引 `i` 或在 `i` 处具有不同的字符，则最长公共前缀在索引 `i` 之前结束。最长公共前缀是 `strs[0].substring(0, i)`。
3.  **第一个字符串的所有字符都匹配：** 如果遍历 `strs[0]` 的循环完成，则 `strs[0]` 本身就是最长公共前缀。

### 解题步骤详解
1.  如果 `strs` 为 `null` 或 `strs.length == 0`，则返回 `""`。
2.  迭代 `i` 从 `0` 到 `strs[0].length() - 1`（第一个字符串中字符的索引）。
    a.  令 `charToMatch = strs[0].charAt(i)`。
    b.  迭代 `j` 从 `1` 到 `strs.length - 1`（数组中其他字符串的索引）。
        i.  如果 `i >= strs[j].length()`（当前字符串 `strs[j]` 较短）或 `strs[j].charAt(i) != charToMatch`（字符不匹配）：返回 `strs[0].substring(0, i)`。
    c.  （如果内部循环完成，则 `charToMatch` 在此位置 `i` 是公共的）
3.  如果外部循环完成，则整个第一个字符串 `strs[0]` 是公共前缀。返回 `strs[0]`。

### Java 代码实现
```java
class Solution {
    // 方法：找出字符串数组中的最长公共前缀
    public String longestCommonPrefix(String[] strs) {
        // 处理边界情况：如果输入数组为 null 或为空，
        // 则不存在公共前缀，因此返回空字符串。
        if (strs == null || strs.length == 0) {
            return "";
        }

        // 数组中的第一个字符串被视为前缀的初始参考。
        // 我们将遍历其字符。
        // 最长公共前缀的长度不能超过任何字符串的长度，
        // 特别是如果我们使用第一个字符串作为基础，则不能超过第一个字符串的长度。
        for (int i = 0; i < strs[0].length(); i++) {
            // 获取第一个字符串中当前位置 `i` 处的字符。
            char charToMatch = strs[0].charAt(i);

            // 将此字符与数组中所有其他字符串（从第二个字符串开始）
            // 在相同位置 `i` 处的字符进行比较。
            for (int j = 1; j < strs.length; j++) {
                // 检查两个不匹配的条件：
                // 1. 如果当前字符串 `strs[j]` 的长度小于索引 `i`（即 `i == strs[j].length()`），
                //    这意味着 `strs[j]` 在此位置没有字符。
                // 2. 如果字符 `strs[j].charAt(i)` 与 `charToMatch` 不匹配。
                if (i == strs[j].length() || strs[j].charAt(i) != charToMatch) {
                    // 如果任一条件为真，则公共前缀在索引 `i` 之前结束。
                    // 因此，最长公共前缀是第一个字符串从索引 0 到（但不包括）`i` 的子字符串。
                    return strs[0].substring(0, i);
                }
            }
            // 如果内部循环完成，则表示索引 `i` 处的 `charToMatch`
            // 对于到目前为止处理的所有字符串都是公共的。
        }

        // 如果外部循环完成，则表示第一个字符串的所有字符
        // 都是所有字符串公共前缀的一部分。
        // 因此，第一个字符串本身就是最长公共前缀。
        return strs[0];
    }
}
```

### 核心数据结构
**字符串数组 (`String[] strs`)：** 输入。此方法不需要复杂的数据结构；它主要使用字符串字符访问和子字符串操作。

### 主要算法思想
**垂直扫描（逐字符比较）：** 该算法迭代字符位置（列），并针对每个位置检查所有字符串是否共享相同的字符。**字符串操作：** 访问特定索引处的字符 (`charAt`) 和创建子字符串 (`substring`)。
